# roman

Each line of standard input is either a number from 1 to 3999, which you print as a Roman
numeral, or a Roman numeral in standard form (`IV`, not `IIII`; `XC`, not `LXL`) for a number
from 1 to 3999, which you print as a number. Print `invalid` for anything else, including
numbers outside the range and numerals not in standard form.
